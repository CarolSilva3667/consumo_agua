# AquaControl

Aplicativo mobile desenvolvido em Flutter para controle do consumo diário de água.

## Funcionalidades

* Cadastro de consumo de água
* Cálculo da meta diária
* Porcentagem da meta atingida
* Visualização dos registros
* Edição e exclusão de registros
* Armazenamento local
* Tema claro e escuro

## Cálculo

A meta diária é calculada pela fórmula:

**Peso × 35 ml**

Exemplo:
60 kg × 35 = **2.100 ml por dia**

## Tecnologias

* Flutter
* Dart
* Shared Preferences

## Como executar
Instale as dependências:

```bash
flutter pub get
```

Execute o aplicativo:

```bash
flutter run
```
